6.2.1 解説

頻出パターンマイニングはアイテムセットマイニングなどとも呼ばれます [57, 58]。データベースから検索条件として用いることができる高頻度なパターンを発見する手法です。

超電導転移温度 (\(T_c\)) を例に取り具体的に説明します [59]。最初に超電導が発見された水銀の \(T_c\) は 4.2K、鉛の \(T_c\) は 7.19K です。\(T_c\) は時代とともに高くなり、1990年代には 30K を超える \(T_c\) を持つ銅酸化物超電導体 \(\text{LaBaCuO}\), \(\text{LaSrCuO}\), \(\text{YBaCuO}\) などが見つかりました。21世紀に入ると更に高圧で 287K の \(T_c\) を持つ \(\text{CSH}\) 系が見つかりました。

このデータから物質の組成と \(T_c\) の相関を議論します。上の説明文だけから \(T_c\) を 30K より上か、そして \(T_c\) が 200K より上かで分け、化学式は元素名だけを用いて、表 6.1 にまとめました1。

物質の組成が分からないので、残念ながら、構成元素の特徴量に平均値、標準偏差などの操作を行い物質の説明変数とすることは適切ではないでしょう。この表を単に物質の構成元素と \(T_c\) の条件式の要素（アイテム）に直します。このアイテムの集合をトランザクションと呼びます。

それぞれの物質に対応するトランザクション (\(T_i\)) を 表 6.2 に示します。条件 \(T_c > 200\) が満たされると \(T_c > 30\) も満たされるので、物質 \(\text{CSH}\) のトランザクションに \(T_c > 30\) を加えています。

アイテム群も各物質に対してスパースな表現になっています。この場合によく用いられるのが、頻出集合や相関ルールと呼ばれる規則を求める頻出パターンマイニングと呼ばれる手法です。

例えば、このデータベースの頻出集合は、\(\{T_c > 30\}\) が 4 件、\(\{T_c > 30, \text{Cu}, \text{O}\}\) が 3 件あります2。更に、相関ルールでは、「\(X\) が起これば \(Y\) が起こる頻度が高い」ことを次の形式で表します：

\(X \Rightarrow Y\)

ここで、\(X\) と \(Y\) は同じアイテムを含まない集合で、\(X\) を前提部 (antecedent)、\(Y\) を結論部 (consequent) と呼びます。このトランザクションでは、\(\text{Cu}\) と \(\text{O}\) からなる物質は 100% の頻度で \(T_c > 30\) を満たしているため、例えば、\(\{\text{Cu}, \text{O}\} \Rightarrow T_c > 30\) という相関ルールが導かれます。

[1] 評価指標

頻出パターンマイニングでよく用いられる評価指標には以下があります。

  • \(\text{support}(X)\) （支持度）
    \(= \text{条件 } X \text{ を満たすトランザクション数} / \text{全トランザクション数}\)
    \(X = \{\text{Cu}, \text{O}\}\) の場合、\(\text{support}(X) = 3/6 = 0.6\) です。
  • \(\text{confidence}(X, Y)\) （信頼度）
    \(= \text{条件 } X \text{ と } Y \text{ を共に満たすトランザクション数} / \text{条件 } X \text{ を満たすトランザクション数}\)
    \(X = \{\text{Cu}, \text{O}\}\), \(Y = T_c > 30\) の場合、\(\text{confidence}(X, Y) = 3/3 = 1\) です。上の例では support, confidence ともに割合としましたが、件数とする場合もあります。

1 温度を示す K を省略しました。

2 それらの部分集合 \(\{\text{Cu}, \text{O}\}\), \(\{\text{Cu}\}\), \(\{\text{O}\}\) も 3 件あります。
